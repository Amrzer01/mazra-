# المزرعة السعيدة (Happy Farm Egypt) 🌿🎈
### منصة السياحة الريفية ومنطاد الأقصر الطائر | Luxury Agritourism & Luxor Balloon

موقع وتجربة سياحية ريفية مصرية مستوحاة من عراقة ريف مصر وسحر النيل وشلالات الفيوم ورحلات منطاد الأقصر فجراً.

---

## ✨ المميزات الرئيسية
- 🎈 **رحلات منطاد الأقصر الطائر فجراً**: التحليق فوق معابد الأقصر وحقول القصب عند الشروق (ارتفاع 1500 قدم).
- 🌴 **وجهات استكشافية أصيلة**: بساتين الأقصر، شلالات الفيوم وقرية تونس، وجزر أسوان ومزارع المانجو.
- 🏺 **استوديو الفخار التفاعلي**: تجربة تلوين وتخصيص الآنية الفخارية مباشرة في الموقع بتقنية SVG حية.
- 🧺 **تقويم حصاد الفواكه المصرية**: استعراض مواسم قطف المانجو، العنب، التين، الزيتون، والفراولة.
- 🧮 **حاسبة أسعار ذكية وحجز فوري**: حساب دقيق للتذاكر، خيارات الإفطار الفلاحي والغداء الريفي، وإصدار بطاقة صعود وحجز (Boarding Pass) فوري وتأكيد عبر واتساب.
- 🎵 **محاكي أصوات الطبيعة ونسيم الحقول**: Web Audio API لتوليد أصوات الريف وزقزقة العصافير بدون ملفات صوتية خارجية ثقيلة.
- 🌐 **ثنائي اللغة بالكامل (العربية / الإنجليزية)**: مع طباعة عربية احترافية (`Readex Pro`, `Cairo`, `Marhey`, `Amiri`).

---

## 🚀 تشغيل الموقع محلياً
يمكن فتح الموقع مباشرة عبر فتح `index.html` في أي متصفح، أو تشغيل خادم محلي:
```bash
python -m http.server 8085
```
ثم فتح المتصفح على: `http://localhost:8085`
